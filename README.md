\# Skin Cancer Detection using CNN



A Deep Learning project for detecting \*\*benign\*\* and \*\*malignant\*\* skin cancer images using a Convolutional Neural Network (CNN) built with TensorFlow and Keras.



\---



\## Overview



This project trains a CNN model to classify skin cancer images into:



\- Benign

\- Malignant



The model was trained on a melanoma skin cancer image dataset and evaluated using accuracy, confusion matrix, and classification report metrics.



\---



\## Technologies Used

\- TensorFlow / Keras

\- OpenCV

\- Pandas
